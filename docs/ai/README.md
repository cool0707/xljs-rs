# AI チャットでスクリプトを作る

Claude・Gemini・Copilot などの AI チャット（無料版や軽量モデルを含む）に xljs のスクリプトを書いてもらうための資料です。
AI は xljs を知らないので、そのままだと Node.js 用のコード（`require("fs")` など）を書いてしまいます。最初にこの資料を渡してください。

| ファイル | 内容 | 大きさ |
|---|---|---|
| [`prompt.md`](prompt.md) | AI への指示（回答の決まり・よくある間違い）＋要点のリファレンス＋回答例。**これだけで基本的な集計・変換は書ける** | 約 8,000 字 |
| [`reference.md`](reference.md) | 詳しいリファレンス（全オプション・書式・フォーム・表・アプリモード）とレシピ 6 本 | 約 22,000 字 |
| [`copilot/instructions.md`](copilot/instructions.md) | Copilot のエージェント用の指示（`prompt.md` を 8,000 字以内に縮めたもの） | 約 4,300 字 |
| [`copilot/skills/xljs-reference/SKILL.md`](copilot/skills/xljs-reference/SKILL.md) | スキル版のリファレンス（`reference.md` と同じ内容） | 約 22,000 字 |
| [`copilot/skills/vba-port/SKILL.md`](copilot/skills/vba-port/SKILL.md) | Excel マクロ（VBA）移植用のスキル。素直な書き方への置き換え、不要なコードの省略、手順の見直しの提案 | 約 4,000 字 |

配布 zip にも `docs/ai/` として同梱しています。

## 使い方

### どのチャットでも（貼り付け）

1. `prompt.md` を開いて全文をコピーし、新しいチャットの最初のメッセージとして貼り付けて送信する。
2. 続けて、やりたいことを書く（下の「頼み方のコツ」）。
3. 返ってきたコードを `.js` ファイル（例: `集計.js`、文字コードは UTF-8）に保存し、`xljs.exe` にドラッグ＆ドロップして実行する。

入力欄の文字数に上限があるチャット（Microsoft 365 Copilot など）では `prompt.md` だけを貼ってください。ファイルを添付できるなら `reference.md` を添付すると、書式・フォームなど細かい指定も正確になります。

### 毎回貼らなくてよい設定

| サービス | 設定する場所 |
|---|---|
| Claude | プロジェクトを作り、「指示」に `prompt.md`、「ファイル（ナレッジ）」に `reference.md` |
| Gemini | Gem を作り、「カスタム指示」に `prompt.md`、「知識」に `reference.md` |
| ChatGPT | GPT（またはプロジェクト）の「指示」に `prompt.md`、ファイルに `reference.md` |
| Microsoft 365 Copilot | エージェントを作れる場合は「指示」に `copilot/instructions.md`（8,000 字の上限に収まる）、スキルに `copilot/skills/` の 2 つ（スキルが使えなければ「知識」に `reference.md`） |
| GitHub Copilot（VS Code） | スクリプトのフォルダに `.github/copilot-instructions.md` として `prompt.md` を置く。`xljs init` で型定義も出すと補完が効く |

## Excel マクロ（VBA）を移植する

1. マクロ付きのブック（.xlsm など）を `xljs.exe` にドラッグ＆ドロップし、VBA コードをテキストファイルに保存する（コマンドなら `xljs vba ブック.xlsm`）。
2. `prompt.md` を貼ったチャットに、「この Excel マクロを xljs に移植してください」と書いて、保存したテキストを貼る（または添付する）。
   スキルを使えるチャット（Copilot のエージェント、Claude のスキルなど）には `copilot/skills/vba-port/SKILL.md` を登録し、使えないチャットでは `prompt.md` に続けて貼るか添付してください。
3. 入力ブックの形（シート名・見出し・列名）も書くと確実です。マクロの中身は AI がまず説明するので、意図どおりか確かめてから使ってください。

## 頼み方のコツ

- **入力ファイルの形を具体的に書く**: シート名、見出しが何行目か、列名（「日付・顧客名・商品・数量・金額」）、1 ファイルか複数か。見出しと数行を（個人情報を消して）貼るのがいちばん確実です。
- **出力の形を書く**: 「顧客ごとの件数と合計を新しい Excel に」「Shift_JIS の CSV で」「元のファイルと同じフォルダに」など。
- **使い方を書く**: AI は入力をフォーム（1 画面に入力欄と実行ボタン）で受け取るスクリプトを書きます。タスクスケジューラーや他のアプリから自動で実行するなら「画面を出さずに自動実行したい」、一度きりの作業なら「使い捨てでよい」と書くと、フォームなしで書きます。
- **一度に頼みすぎない**: まず動くものを作ってもらい、「金額の列に 3 桁区切りを付けて」のように足していきます。
- **エラーが出たら**: エラーダイアログの「コピー」ボタンで全文をコピーし、「このエラーが出ました」と貼って直してもらいます。
- 実行する前に構文だけ確かめるには `xljs check 集計.js`。
- 本番のファイルで試す前に、コピーしたファイルで試してください（上書き保存するスクリプトの場合は特に）。

## 依頼の例

```
フォルダの中に支店ごとの売上ファイル（東京.xlsx、大阪.xlsx…）があります。
各ファイルの「売上」シートは 1 行目が見出しで、列は「日付・担当・商品・数量・金額」です。
全ファイルをまとめて、担当ごと・月ごとの金額の合計表を作り、新しい Excel に保存したいです。
```

## 資料を更新するとき（開発者向け）

- API を変えたら `types/xljs.d.ts` と合わせて `prompt.md`・`reference.md`・`copilot/instructions.md` も直し、`reference.md` を `copilot/skills/xljs-reference/SKILL.md` にコピーする（`go test` が一致を検査する）。ここに書いたことは AI がそのまま使うので、存在しないオプションや古い書き方を残さない。
- `go test ./internal/engine` がコードブロック（```js）の構文と、`prompt.md` の長さ（貼り付けの上限に収まるよう 15,000 字以内）、`copilot/instructions.md` の長さ（8,000 字以内）を検査する。
- コード例は `xljs --ui=mock --ui-answers=応答.json` で実際に動かして確かめる。
