# Font Awesome Free

[Font Awesome Free](https://fontawesome.com/) 7.3.1（アイコン: CC BY 4.0、フォント: SIL OFL 1.1、CSS: MIT。`LICENSE.txt`）。
npm パッケージ `@fortawesome/fontawesome-free` の `css/all.min.css` と `webfonts/*.woff2` を変更せずに置いている。
アプリモードのページから `https://app.xljs/_xljs/fontawesome/css/all.min.css` で読み込める（`<link rel="stylesheet" href="/_xljs/fontawesome/css/all.min.css">`）。

更新するときは新しいパッケージの同じファイルで置き換え、この README の版を直す（`builtin_test.go` が CSS から参照するフォントの有無を検査する）。
